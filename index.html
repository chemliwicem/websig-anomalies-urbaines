    Fonctionnalités du Sprint 3

    • US07 : modification des anomalies fictives ajoutées localement.
    • US08 : tableau de bord par catégorie, actualisé automatiquement.
    • US09 : interface responsive pour téléphone.

    Les fonctionnalités des Sprints 1 et 2 sont conservées. Les trois exemples initiaux sont en lecture seule ; les ajouts locaux sont modifiables. Les données ajoutées ne sont pas partagées entre utilisateurs : une base de données sera nécessaire ultérieurement.

    Critères d'acceptation du Sprint 3 — à vérifier lors de la revue

    1. La carte et les trois anomalies fictives du Sprint 1 s'affichent.
    2. Le formulaire refuse les champs vides et les coordonnées invalides.
    3. Une anomalie fictive ajoutée apparaît sur la carte et dans la liste.
    4. Le clic sur un marqueur affiche titre, catégorie, description et coordonnées.
    5. Le filtre par catégorie agit sur la carte et sur la liste.
    6. Après actualisation, les ajouts restent présents dans le même navigateur si le stockage local est disponible.
    7. Les anomalies ajoutées localement peuvent être modifiées, puis sauvegardées.
    8. Le tableau de bord reflète les ajouts et les modifications de catégories.
    9. L'interface reste utilisable sur smartphone.
